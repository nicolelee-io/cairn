## Attachments

Files that aren't photos, limited to what Day One accepts besides images: PDF, MP4, MOV and M4A.

- Table `attachment`: like `photo` (null `entry_id` until saved, tombstones, own `rev` in the sync feed) with `kind` (`video|audio|pdf`), one `path` (`attachments/<user_id>/<sha256>.<ext>`, no derivatives) and the uploaded `filename`. Text reference: `![<filename>](attachment:<id>)` (`attachmentMarkdown` in `packages/shared/src/mediaRefs.ts`). Attaching, ordering, tombstoning on removal and `removeMediaIds` are the photo code, generalised in `repo/media.ts`.
- `PUT /api/attachments?name=<file name>`: the raw body, streamed to a temp file while hashing (`upload.ts` `ingestAttachment`), never parsed as multipart, so a 95 MB video doesn't sit in memory. The type comes from the first bytes (`sniffAttachment`: `%PDF-`, or an ISO-BMFF `ftyp` brand: `qt  ` MOV, `M4A `/`M4B ` M4A, HEIC/AVIF brands refused, anything else MP4); everything else is a 415. Size: `GET/PUT /api/attachments/limit` (`limit.ts`, `app_setting` `attachment_max_mb`), default and ceiling `ATTACHMENT_MAX_MB` = 95 (Cloudflare refuses requests over 100 MB); a declared `Content-Length` over it is refused before reading, the stream is cut past it.
- `GET /api/attachments/:id[?download]`: ownership-checked, `inline` (or `attachment`) `Content-Disposition` with the file name, ETag, single-range `Range` support (`parseRange`; Safari needs it for video). `app.ts` gives these responses their own CSP with `object-src 'self'`: the app's `object-src 'none'` makes Chrome's PDF viewer render a blank page.
- `DELETE /api/attachments/:id` tombstones it and strips its reference from the entry text. Cleanup is `photos/gc.ts` `collectMediaGarbage`.
- Import/export: `storeAttachmentStream` (the importer: the same temp-file-while-hashing `spool` as an upload, with no size cap of its own: Import from Settings checks each file's size before calling it, see `import/CLAUDE.md`; the declared type is kept with a warning when the bytes aren't recognised) and `ATTACHMENT_LISTS` in `import/dayone/map.ts`. See `import/CLAUDE.md` and `export/CLAUDE.md`.
- Timeline cards carry `hasAttachments` (`entryCards`, and `timeline()` in `lib/localRead.ts`), shown as a paperclip on `EntryCard`. Search takes `attachments=true` (an `EXISTS` on live attachment rows), which like `starred` works with no words; the Search page's Attachments chip sets it (`?files=1`).
- Web: `components/AttachmentView.tsx` (reader), the editor chip in `cm/livePreview.ts`, `lib/upload.ts` / `lib/useUploads.ts`, Settings `AttachmentLimitCard`. Offline copies hold the records, never the files; the service worker doesn't touch `/api/attachments/*`.
